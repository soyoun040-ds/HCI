# HCI 7조 — 네이버 메이트 스페셜 지원금 평가 에이전트

이미 선정된 네이버 메이트 중에서 스페셜 지원금 대상자가 되려면 무엇을 개선해야 하는지 알려주는 평가 에이전트와 대시보드를 만드는 프로젝트예요.

## 크롤러 (`crawler.py`)

```bash
pip install requests beautifulsoup4 lxml

# 메이트 전체 목록 + 스페셜 라벨만 받기
python crawler.py --collector 이름 --targets-only

# 분야 지정 크롤링 (스페셜 대상자 전원 포함)
python crawler.py --collector 이름 --topics 7-12 --with-special --workers 5
```

- 2026-07-31 이전 데이터만 수집해요.
- 중간에 끊겨도 같은 명령을 다시 실행하면 이어서 수집해요.
- 결과는 `out/`에 저장되고, 저장소에는 올리지 않아요 (제3자 댓글 포함, 대용량).
