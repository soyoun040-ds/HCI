# HCI 7조 — 네이버 메이트 스페셜 지원금 평가 에이전트

이미 선정된 네이버 메이트 중에서 스페셜 지원금 대상자가 되려면 무엇을 개선해야 하는지 알려주는 평가 에이전트와 대시보드를 만드는 프로젝트예요.

```bash
pip install requests beautifulsoup4 lxml
```

## 1. 크롤러 (`crawler.py`)

```bash
# 메이트 전체 목록 + 스페셜 라벨만 받기 (1분)
python crawler.py --collector 이름 --targets-only

# 분야 지정 크롤링
python crawler.py --collector 이름 --topics 1-6 --workers 5 --out-dir out2

# 이미 받아둔 본문이 있으면 재사용 (겹치는 글은 다시 안 받음)
python crawler.py --collector 이름 --topics 7-12 --with-special --workers 5 \
    --out-dir out2 --reuse-posts out/posts_이름.csv
```

- 2026-07-31 이전 글만 수집해요.
- 중간에 끊겨도 **같은 명령을 다시 실행하면 이어서** 수집해요.
- 인터넷이 끊기면 실패로 처리하지 않고 복구될 때까지 기다려요.
- 결과는 `out/`(또는 `--out-dir`)에 저장되고, 저장소에는 올리지 않아요.

### 표본 3종

글 목록을 **끝까지 전부 훑은 뒤**, 본문은 아래 세 표본에 뽑힌 글만 받아요. `sample_set` 칼럼으로 구분해요 (겹치면 `recent_top|alltime_top`처럼 `|`로 연결).

| 표본 | 뽑는 방법 | 무엇을 보는가 |
|---|---|---|
| `recent_top` | 7/31 이전 최근 200개 중 좋아요+댓글 상위 50 | 요즘도 통하는 콘텐츠인가 |
| `alltime_top` | 전 기간 좋아요+댓글 상위 50 | 대표작과 최고 수준 |
| `random` | 연도당 5개씩 무작위, 최대 30개 | 평소 글의 평균 수준 |

### 출력 파일

| 파일 | 내용 |
|---|---|
| `mates_all.csv` | 메이트 전원(2,167명) + 스페셜 지원금 라벨 |
| `blogs_이름.csv` | 블로그 1개 = 1행 |
| `posts_이름.csv` | 본문을 받은 글 1개 = 1행 (`sample_set`으로 표본 구분) |
| `postmeta_이름.csv` | **7/31 이전 전체 글**의 날짜·좋아요·댓글·카테고리 (본문 없음) |
| `crawl_이름.log` | 진행 로그 |

`postmeta`는 발행 주기, 주제 일관성, 반응 추세를 블로그 전 기간으로 계산할 때 써요.

## 2. 인용수 스냅샷 (`snapshot.py`)

```bash
python snapshot.py --workers 5     # 약 8분
```

블로그 API는 인용수를 **누적 / 이번 달 / 선정 기간(2개월 전)**만 줘요. 이번 달 값은 달이 바뀌면 사라지므로 **월말에 찍어둬야** 해요.

- 9월 인용수 = **10월 스페셜 지원금 선정 기준값**
- 결과: `out/snapshot_YYYYMMDD_HHMM.csv`, `out/snapshot_latest.csv`

## 3. 시점 정리 (중요)

| 항목 | 기준 |
|---|---|
| 9월 메이트 (2,157명) | 7월 1~31일 인용수 |
| 9월 스페셜 (75명) | **8월 메이트** 중에서 8월 1~31일 인용수 + 전문성·활동성·신뢰도·이용자 반응·검색 기여도 |

스페셜은 **전월 메이트**를 대상으로 뽑혀서, 9월 메이트 명단과 모집단이 어긋나요 (75명 중 10명이 9월 메이트 목록 밖). 10월 스페셜은 9월 메이트 중에서 뽑히므로, 9월 인용수 스냅샷과 10월 초 스페셜 명단을 합치면 **후보군·기준값·라벨이 모두 맞는 데이터셋**이 돼요.
