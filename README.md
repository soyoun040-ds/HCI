# HCI 7조 (soonejumin) — Naver Mate Creator Reward Agent

네이버 블로그를 평가하는 **AI 에이전트**와, 그 평가 결과와 보상 산정 근거를 보여주는 **대시보드(사용자용 / 관리자용)**를 만드는 프로젝트예요.

| 기획서 | `인컴상/HCI_Team7_onejuso_Week2.pdf` |

## 프로젝트 방향

**평가 기준을 우리가 직접 설계해요.** 네이버의 선정 기준 중 핵심인 AI 브리핑 인용수는 **메이트로 선정된 블로그만 공개**돼서, 일반 블로그에는 적용할 수 없어요. 그래서 네이버 검색 공식 블로그가 밝힌 [**잘 인용되는 글의 조건**](https://blog.naver.com/naver_search/224296857688)을 프록시 지표로 삼아 콘텐츠를 채점해요.

> 직접 경험한 지식 · 일관된 주제 · 거짓 없는 진정성 · 읽기 쉬운 구조 · 최신성 유지
> (감점) 무분별한 복제·생성 · 과도한 광고 · 무관한 키워드 · 무관한 미디어 · 부정확한 정보

어떤 항목을 넣을지, 항목별 가중치를 어떻게 줄지 **기준을 정립하는 것 자체가 이 프로젝트의 기여점**이에요. 선행연구로 근거를 대고, 없으면 기준의 적절성을 논증해요.

**수집한 메이트 데이터는 검증용으로 써요.** 메이트는 인용수를 알 수 있으니, 우리 점수가 실제 인용수·선정 결과와 얼마나 맞는지로 기준의 타당성을 확인해요.

| **정민** (47, 5년차 DIY 블로거, 메이트 선정자) | 왜 선정됐는지에 대한 근거, 다음 단계로 가기 위한 개선 방향 |
| **우진** (23, 대학생, 일반 블로그 유저) | 선정 기준에 대한 정보, 실제 사례 기반 벤치마킹 |
| **지현** (29, 콘텐츠 정책 운영팀) | 1차 자동 스코어링, 판단 근거, 이상 신호 플래깅 |

**공개 범위는 대상에 따라 나눠요.** 일반 사용자와 메이트에게는 결과와 이해하기 쉬운 근거, 개선 방향을 주고, 관리자에게는 세부 평가 근거·이상 신호·원자료·AI의 판단 과정까지 줘요.

## 코드

```bash
pip install requests beautifulsoup4 lxml
```

| 파일 | 역할 |
|---|---|
| `crawler.py` | 네이버 블로그 수집. **자세한 설명과 피처 목록은 [CRAWLER.md](CRAWLER.md)** |
| `snapshot.py` | 월말 인용수 스냅샷 (다음 달 스페셜 지원금 선정 기준값) |

```bash
# 분야 지정 크롤링
python crawler.py --collector 이름 --topics 1-6 --workers 5 --out-dir out2

# 월말 인용수 스냅샷 (약 8분)
python snapshot.py --workers 5
```

### 분야 번호 (`--topics`)

| 번호 | 분야 | 담당 |
|---|---|---|
| 1-6 | 국내여행, 해외여행, 푸드, 레시피, 패션, 뷰티 | 하나 |
| 7-12 | 리빙, 반려동물, 건강, 육아, 영화, 방송 | 소연 |
| 13-18 | 애니메이션, 공연/전시, 음악, 책, 예술, IT/테크 | 민서 |
| 19-25 | 자동차, 교육, 경제, 사회, 스포츠, 게임, 취미 | 주원 |

수집 결과(`out/`, `out2/`)는 제3자 댓글이 포함돼 있고 용량이 커서 저장소에 올리지 않아요.
